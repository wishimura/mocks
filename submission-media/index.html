USER-GENERATED MEDIA

運営が発信する記事と、ユーザーから集まる体験談でコンテンツが育っていく投稿型メディア。
MVP要件を整理するためのデザインモックです。

読者・投稿者（一般ユーザー）

ログイン・会員登録 / 記事を読む / リアクション / アンケート回答 / 体験談を投稿

運営・編集部（管理者）

記事の掲載 / 投稿の確認・編集・承認 / 会員・アンケート管理
MVPの範囲（想定）
まずは「運営記事の掲載 → ユーザー投稿 → 運営の承認 → 公開 → リアクション」までの一本の流れ。 ランキング・会員機能・検索は段階的に拡張する前提で画面を用意しています。

※ 要件整理用のモックです（DB接続・実データなし）
