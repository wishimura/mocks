# アセット規格メモ（建物 / アバター / 地面 / 小物 / 背景）

街の見た目はすべて画像アセットで作る。以下の規格に揃えると、エンジン（PixiJS）にそのまま載る。
共通ルール：**手描きペインタリーの絵本RPG調 / 光は左上から / 統一した画角と縮尺**。

## 共通の最重要ルール
- **接地点 = 画像の「下端・中央」**（建物も人も小物も、地面に接する点をここに置く）
- 透過は **本物のアルファPNG**（“市松模様を絵として描く”のはNG。怪しければ単色#00FF00背景で出して後で抜く）
- 同種アセットは **縮尺を揃える**（並んだとき大きさが破綻しない）

## 1. 建物（buildings/）
| 項目 | 値 |
|---|---|
| 形式 | 透過PNG |
| 視点 | アイソメトリック（2:1の見下ろし。屋根＋正面＋側面が少し見える） |
| サイズ | 幅512px（縦は内容により可変・現状585〜629px） |
| 接地点 | 下端中央。1階の幅 ≒ 画像幅の約60% |
| 既存 | `bakery.png` `tea.png` `greengrocer.png`（512×~600, RGBA） |

AIプロンプト例：
```
アイソメトリックのゲーム用アセット。1棟だけの小さなお店「パン屋」。木組み（ハーフティンバー）の絵本風RPG、
手描きペインタリー、光は左上。屋根＋正面＋側面が少し見える2:1の角度。正方形(1:1)・高解像度。
建物が地面に接する点を画像の下端・中央に。左右の余白は均等。背景は完全に透明（市松模様は描かない）。建物だけ。
```

## 2. アバター（avatars/） ※未着手
| 項目 | 値 |
|---|---|
| 形式 | 透過PNG |
| 視点 | 正面〜やや見下ろし、全身・立ち姿 |
| サイズ | 512×512px（ゲーム内は小表示） |
| 接地点 | 足元＝下端中央。全身が画像高さの約75% |
| 種類 | 10種程度 |

AIプロンプト例：
```
絵本風RPGのゲーム用キャラ（アバター）1体、全身・立ち姿。手描きペインタリー、光は左上、正面〜やや見下ろし。
正方形(1:1)・高解像度。足が地面に着く位置を下端・中央に。背景は完全に透明（市松は描かない）。キャラだけ。
```

## 3. 地面・道（ground/）
| 項目 | 値 |
|---|---|
| 形式 | 不透明PNG・**シームレス（タイル状に繰り返せる）** |
| 視点 | 真上から（パース・立体・影なし、均一な光） |
| サイズ | 512×512px |
| 既存 | `grass.png`（草）, `cobble.png`（石畳） 各512×512, RGB |

## 4. 小物（props/）
| 項目 | 値 |
|---|---|
| 形式 | 透過PNG、建物と同じアイソメ・光 |
| 接地点 | 下端中央 |
| 例 | 木・街灯・樽・井戸・ベンチ・立て看板・花壇 |
| 既存 | `tree.png`（320×330, RGBA） |

## 5. 背景（bg/）
| 項目 | 値 |
|---|---|
| 用途 | 画面端の暗がり/全画面時の余白 |
| 既存 | `forest.png`（768×432, RGB・夕暮れの森） |
| 備考 | 通常はコードのビネット（暗がり）で代替可 |

## 命名・運用
- ファイル名は英数字で内容がわかるように（`building_bakery.png` 等）
- 本番では Supabase Storage のバケット（`buildings` / `avatars` / `products` / `ground`）に格納し、DBはURL（path）を持つ
- 建物・アバターの**テンプレ追加は管理者のみ**（要件どおり）
